Kanban Board — 10 ขั้นตอนตามลำดับ (ย้อนกลับเฉพาะ Revision / Reject)

บอร์ดเรียงตาม 10 ขั้นตอนตั้งแต่ Sale ถึง Done แม้แผนกเดิมจะปรากฏซ้ำก็เป็นคนละขั้นตอน · การส่งงานปกติเดินหน้าเท่านั้น ส่วน Customer Edit / QC Reject / Customer ไม่เซ็น สามารถส่งย้อนกลับเพื่อแก้ไขพร้อมระบุเหตุผลและเลือกผู้รับเดิมอัตโนมัติ · ลูกค้าไม่จำเป็นต้องเข้าสู่ระบบเอง

Work Detail

ส่งต่อ / รับงาน

R&D — Inkjet Separation

รับงานจาก Sale ตรวจ Brief แล้วจัดทำไฟล์ Adobe Illustrator (.ai) สำหรับ Inkjet Separation ก่อนส่งให้ Prepared

เกณฑ์ส่งงานที่เสนอ: ต้องมีไฟล์ .ai เวอร์ชัน R&D และรายละเอียดงานที่ตรวจสอบได้ (การตรวจทางเทคนิคของไฟล์ยังเป็นขั้นตอนมนุษย์ในต้นแบบ)

Prepared — Color Preparation และ Final Print

มีงาน 2 รอบที่แตกต่างกัน: (1) ใส่สีตาม Inkjet แล้วส่ง Sale ทำ Proof (2) หลังลูกค้า Confirm แล้ว Prepared เตรียมงานและส่ง QC พร้อมงานพิมพ์

Customer Confirm / Edit — รอบที่ 1

Sale ส่ง Proof ให้ Customer และเป็นผู้บันทึกผลการยืนยันหรือรายการแก้ไข

Confirm รอบที่ 1 ≠ เซ็นอนุมัติหลัง QC ต้องแยกสถานะ หลักฐาน วันเวลา และไฟล์เวอร์ชันที่เกี่ยวข้อง

Revision / Issue Tracking

Sale เลือกจุดแก้ไข R&D หรือ Prepared แล้วระบบดึงผู้รับผิดชอบเดิมของแผนกนั้นให้อัตโนมัติ (เช่น R&D คุณนัท) พร้อมเหตุผลและอ้างอิงไฟล์เวอร์ชันเดิม

การแก้ไขต้องไม่ลบงานเดิม และไม่ควรเขียนทับไฟล์ .ai ที่เคยส่งให้ลูกค้าตรวจหรือเซ็นแล้ว

QC — ตรวจพร้อมงานพิมพ์

Prepared ส่งให้ QC ตรวจพร้อมชิ้นงานพิมพ์ → QC ผ่านจึงส่งต่อให้ Sale; หากไม่ผ่านต้องบันทึกเหตุผลและส่ง Rework

Customer Sign-off — รอบที่ 2

หลัง QC ผ่าน Sale ส่งเอกสาร / งานพิมพ์ให้ลูกค้าเซ็น และเก็บหลักฐานก่อนปล่อยผลิต

กรณีลูกค้าไม่เซ็นหรือขอแก้ไขในรอบสุดท้าย ต้องกำหนดเส้นทางกลับและผู้อนุมัติกฎนี้กับ End User

Release to Production

Gate ขั้นสุดท้าย: Customer Confirm ครั้งแรก → Prepared Final → QC Pass → Customer Signed → Production

Adobe Illustrator (.ai) — File Version Management

ไฟล์ทำงานจาก R&D และ Prepared ต้องแยกเวอร์ชันอย่างตรวจสอบได้ รวมถึงไฟล์ Proof, หลักฐาน Confirm, QC และเอกสารเซ็น

Roles & Workflow Configuration (Concept Only)

Roleการดำเนินการที่เสนอ
Saleรับ Brief, เปิดงาน, ส่ง Proof, บันทึก Confirm/Edit, ส่งเซ็น, ส่งผลิต
R&Dรับงาน จัดทำ Inkjet Separation ส่งต่อ Prepared
Preparedรับงาน ใส่สี เตรียม Final และส่ง QC
QCตรวจงานพิมพ์ Pass/Reject และส่งต่อ Sale
Manager / Adminติดตาม KPI, ตั้งค่าผู้ใช้งาน / สถานะ / กฎการส่งต่อ

Business Rules ที่ต้องยืนยัน

  1. แต่ละขั้นตอนต้องมีผู้รับผิดชอบหลักและกฎการรับงาน
  2. เมื่อส่งงานย้อนกลับ ให้เลือกเจ้าของงานเดิมในแผนกนั้นอัตโนมัติ (เช่น R&D คุณนัท) โดยไม่ต้องพิมพ์ชื่อ; ถ้ายังไม่เคยมอบหมายให้กำหนดเพียงครั้งแรก
  3. กรณีผู้รับงานเดิมไม่พร้อม ต้อง Reassignment โดยหัวหน้าแผนก/Admin พร้อมเหตุผลและ Audit Log
  4. ไฟล์ AI ใดเป็นไฟล์ที่ลูกค้าดู และไฟล์ใดเป็นไฟล์พร้อมผลิต
  5. กรณี Customer Edit ต้องกลับ R&D หรือ Prepared ตามเหตุผล
  6. หาก QC Reject หรือ Customer ไม่เซ็น ให้กลับไปขั้นตอนใด
  7. ใครมีสิทธิ์ปล่อยงานเข้าสู่การผลิต

Prototype นี้ไม่ได้เชื่อม Backend, ระบบ Auth, Adobe Illustrator หรือพื้นที่เก็บไฟล์จริง — ห้ามใช้เป็นระบบอนุมัติผลิตจริง
